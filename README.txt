Quiz Platform — Phase 10.1

- Public quiz routes use client slug: /quiz/cliente-slug/year/month/quiz-slug
- Client config lives in /clients/{client-slug}.json
- Quiz content lives in /quizzes/{client-slug}/year/month/quiz-slug.json
- Result sharing generates a 1080x1080 PNG in the browser using html-to-image.
- Native Share can share the PNG file on supported mobile browsers/apps.
- Download image is available as fallback.
- The experience emphasizes remembering and keeping the weekly message present, without competition-oriented language.
